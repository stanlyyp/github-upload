# Processed Observation Data

This repository contains processed observation data for three HUC8 watersheds:

- `gr`: Green River, HUC8 `07090007`
- `er`: Embarras River, HUC8 `05120112`
- `sr`: South Skunk River, HUC8 `07080105`

## Files

Each watershed has processed CSV files for flow, total nitrogen (`tn`), total phosphorus (`tp`), total suspended solids (`tss`), and stations.

The `*_stations.csv` files contain the monitoring site coordinates. In these filenames, `stations` means the observation sites and their coordinate information.
